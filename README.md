# Crypto Arbitrage Scanner - Cross Exchange

Real-time cryptocurrency arbitrage scanner monitoring 21 exchanges and 50+ coins.

## Features
- 🚀 Real-time price monitoring across 21 exchanges
- 💰 50+ coins including large, medium, and volatile caps
- 📊 Automatic fee calculation per exchange
- ⚡ Instant profit/loss calculation
- 🎯 Tier-based trading recommendations
